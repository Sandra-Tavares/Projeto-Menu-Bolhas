# Menu responsivo com animação em bolha

## Objetivo

Estudo de interface web com menu responsivo e animação circular.

## Tecnologias e estrutura

- `index.html`: navegação com links Sobre, Projetos e Contato.
- `style.css`: estilos, media query até 750 px e animação com `clip-path`.
- `app.js`: alterna a classe `active` ao clicar no menu hambúrguer.

## Como visualizar

Abra `index.html` no navegador após revisar as pendências abaixo.

## Pendências identificadas

- O HTML referencia `style1.css`, mas o arquivo disponível é `style.css`.
- O CSS referencia `bg.jpg`, que não consta na raiz.
- A declaração `z-index: 1,` contém uma vírgula em vez de ponto e vírgula.

A execução visual não foi testada e o código não foi alterado nesta revisão.
